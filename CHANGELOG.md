# Changelog

## 1.0.0 — 2026-11-02

First public Windows release.

- NVIDIA NIM and DeepSeek connections with independent API key management.
- Light workspace UI, projects, conversations, editing, deletion and import/export.
- Streaming responses, reasoning display, interruption detection and continuation.
- Full searchable, scrollable model list without a 100-item limit.
- Context ring with cache-hit and cumulative token details.
- Persistent WebView2 profile and Chinese IME-aware keyboard handling.
- Custom application icon and stable Windows taskbar identity.
- Loopback-only backend, cross-origin rejection and sanitized Markdown.
- Locked dependencies, Windows build workflow, portable ZIP and checksums.
